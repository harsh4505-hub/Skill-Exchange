01 / WORKFLOW

HOW THE PLATFORM WORKS

A clear, simple 4-step path to learning new skills and sharing your expertise with peers on campus.

01
Create Your Profile

Add the skills you can teach and the skills you want to learn. Specify proficiency levels, academic department, and semester.

02
Discover Skills

Search the directory for peers teaching the topics you need. Filter by academic domain, proficiency, or reciprocal availability.

03
Connect

Send a structured exchange proposal offering one of your skills in return. Coordinate learning timelines via the built-in messenger.

04
Exchange Knowledge

Conduct peer study sessions, teach what you know, learn what you need, and earn verified skill badges upon exchange completion.

03 / CREDIBILITY

VERIFIED SKILL CREDENTIALS

Establish trust on campus through rigorous, evidence-based skill verification reviewed by faculty administrators.

COMPULSORY

Projects

Submission of a tangible practical project is mandatory. Provide a live GitHub repository, deployment link, or digital portfolio proving applied mastery.

✓ GitHub / Live URL required
COMPULSORY

Experience

Documented experience is mandatory. Detail practical roles such as technical committee membership, club mentoring, or open-source contribution history.

✓ Organization & role validated
OPTIONAL

Certificate

Course completion credentials or professional vendor certifications are accepted as optional supporting evidence to accelerate the review process.
