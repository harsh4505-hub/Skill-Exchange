02 / HOW IT WORKS

Four Steps to Your First Swap

From listing your skills to a finished exchange — all inside one dashboard.

1. List What You Know

Add the skills you can teach and the ones you want to learn — from Java and Python to Photoshop and public speaking.

2. Get Matched

We rank campus peers by mutual skills, department, college and rating — with a transparent match score on every profile.

3. Propose the Swap

Send an exchange offer: what you'll teach, what you want back, and how you'll meet. They accept in one click.

4. Learn & Track

Schedule sessions, track your learning progress and rate each other when the exchange is complete.
